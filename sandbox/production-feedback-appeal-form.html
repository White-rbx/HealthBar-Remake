Feedback & Appeal · ระบบส่งคำร้องผ่านเบราว์เซอร์

ไม่ต้องใส่รหัสผ่าน, OTP, อีเมล หรือข้อมูลส่วนตัวอื่น ๆ การระบุ Roblox UserId สำหรับ Appeal เป็นเพียงคำกล่าวอ้าง ไม่ใช่การยืนยันตัวตน

ส่งคำร้อง / Submit a request

โปรดอย่าใส่รหัสผ่านหรืออีเมล การอุทธรณ์ยังต้องผ่านการตรวจสอบ

เนื้อหาต้องเป็นไปตามกฎ ArcScriptCenter และไม่ควรมีข้อมูลส่วนตัว

หลักฐานการส่ง / Private receipt

จะแสดงเมื่อส่งสำเร็จเท่านั้น เก็บเลขคำร้องและ Receipt ไว้เป็นความลับ หากปิดหน้านี้โดยไม่ได้บันทึก Receipt อาจตรวจหรือแก้ไขคำร้องไม่ได้

ตรวจสถานะ / Review, Edit or Remove

กรอก Case ID และ Receipt เพื่อดูสถานะ หรือแก้ไข/ลบคำร้องที่ยังอยู่ในสถานะ Reviewing

กำลังโหลดระบบยืนยัน Turnstile…

หน้านี้ให้บริการจาก Production origin เดียวกับ API ไม่ส่ง Turnstile token หรือ Receipt ผ่าน URL ไม่เก็บ Receipt ใน Local Storage
