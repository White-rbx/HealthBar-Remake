# Account leaderboard visibility — isolated QA draft
The previous public, masked leaderboard stays unchanged. This candidate provides a protected web-only draft and a strict Compact Card projection. Default private; the owner explicitly selects nickname, optional appearance, and earned badges. No account identifier, Roblox identifier, login name, raw case data, timestamp or session information is returned in the card. Draft changes are guarded by a live same-origin web session; restricted accounts cannot enable inclusion and can disable it. No public list or ranking is implemented, and no draft authorizes automatic publication. The new route is disabled unless both isolated achievements and leaderboard preview flags are enabled, and requires additive QA migration. Gateway remains exactly five existing operations. Integrate with authorized game transport only after a reviewed consent and visibility contract. Verified ranking metrics are still unavailable: do not invent counts or grant awards from client data. Main and production remain unchanged.
